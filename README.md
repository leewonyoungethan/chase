# 🚓 도둑차 대탈주

훔친 스포츠카로 한밤의 도시를 달리며 경찰을 따돌리는 탑뷰 추격 게임입니다. 라이브러리 없이 캔버스 하나로 동작합니다.

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크 · 후진 |
| A D / ← → | 핸들 |
| Space | 핸드브레이크 드리프트 |
| Shift | 부스터 (니트로) |
| V | 시점 바꾸기 (위에서 / 차 뒤에서) |
| P / Esc | 일시정지 · M 소리 |

모바일에서는 왼쪽 화면 아무 곳이나 눌러 나오는 조이스틱을 가고 싶은 방향으로 밀어 운전합니다(많이 밀수록 빠름, 반대로 당기면 후진하며 돌기). 오른쪽에 드리프트·부스터 버튼이 있습니다.

- 도시는 끝이 없습니다. 달리는 방향으로 거리가 계속 새로 생깁니다(판마다 다른 도시).
- 돈가방($), 니트로 통, 수리 렌치를 주우세요. 노란 화살표가 가리키는 금고를 털면 큰돈을 얻지만 수배 레벨이 오릅니다.
- 수배 레벨(★1~5)이 오를수록 경찰차가 많아지고 빨라지며, ★4부터는 헬기가 따라옵니다. 대신 점수 배율도 같이 오릅니다.
- 드리프트와 아슬아슬하게 스치기로 점수와 부스터를 모으고, 경찰차를 들이받거나 벽에 박게 만들어 폭파하세요.
- 경찰차 근처에서 느려지면 체포 게이지가 찹니다. 경찰 시야에서 6초 동안 벗어나면 수배 레벨이 내려갑니다.
- 🏆 **공유 순위표**: claude.ai 아티팩트로 열면 claude.ai 저장소를, GitHub Pages로 열면 Firebase를 씁니다. 공개 버전(누구나 기록 가능) 설정은 [FIREBASE_SETUP.md](FIREBASE_SETUP.md)를 보세요.
